# Nupis Digital

Landing page em Next.js (App Router), TypeScript estrito, Tailwind CSS 4 e Motion for React.

## Comandos

```bash
npm install
npm run dev
npm run lint
npm run typecheck
npm run build
```

## Configuração

Copie `.env.example` para `.env.local` e preencha `NEXT_PUBLIC_BOOKING_URL` (link de agendamento), `NEXT_PUBLIC_CONTACT_EMAIL` e `NEXT_PUBLIC_CONTACT_PHONE`. Contatos vazios não aparecem no rodapé.
